# muse-widget

Data files for Asuka's Muse home-screen widget (Scriptable).

- `usage.json` — Muse weekly usage (left percent, reset time), updated by Muse.
- `scene_b64.txt` — the latest scene image of Iori (JPEG, Base64 text). The widget fetches this file, decodes it, and displays it.

No personal information is stored in this repository.
